# HabitBuilder App

A modern habit tracker with:
- dashboard summary cards
- weekly progress chart
- monthly calendar view
- habit streaks and progress bars
- local browser storage
- clean responsive layout

## Run locally

1. Download or clone the project.
2. Open `index.html` in your browser.
3. Start adding habits.

No install or build step is required.

## Features

- Add, edit, and delete habits
- Mark habits complete for today
- Track streaks over time
- View weekly charts and monthly calendar
- See habit category summaries
- Data persists automatically in the browser

## Files

- `index.html` — app structure
- `styles.css` — dashboard styling
- `script.js` — logic for habits, analytics, and UI

## Notes

This app stores data in `localStorage`, so it works instantly without a backend or database.
